# Olenro v1.0.0

> Olenro の最初の正式リリース——CC Switch（MIT）をベースにした独立したリブランド fork で、独自のアプリ識別子・設定名前空間・更新チャネルを確立しつつ、CC Switch 3.15.0 の全機能を引き継ぎます。

**[English →](v1.0.0-en.md) | [中文版 →](v1.0.0-zh.md)**

---

## 概要

Olenro v1.0.0 は、独立したプロジェクトとしての Olenro の**最初の正式リリース**です。Olenro は [CC Switch](https://github.com/farion1231/cc-switch)（MIT、上流 v3.15.0）をベースにしており、元の CC Switch プロジェクトとは**関係ありません**。

本リリースは CC Switch 3.15.0 の全機能——Claude Code / Claude Desktop / Codex / Gemini / OpenCode / OpenClaw / Hermes をまたいだプロバイダーの統合管理と切り替え、内蔵プロキシゲートウェイとロールベースのモデルマッピング、使用量ダッシュボード——を引き継ぎつつ、独自の bundle 識別子・設定ディレクトリ・ディープリンクスキーム・更新チャネル・中立化されたプロバイダープリセットを備えた**完全に独立したアプリケーション**として再構築しています。

CC Switch から移行する場合、Olenro は初回起動時に既存の設定を**一度だけ自動でインポート**するため、手動の手順なしでプロバイダーと設定が引き継がれます。

**リリース日**：2026-06-01

---

## ハイライト

- **独立したアプリ識別子**：新しい bundle 識別子 `com.olenro.desktop`、設定ディレクトリ `~/.olenro`、ディープリンクスキーム `olenro://`。Olenro は独立したアプリとしてインストール・実行され、並存できます。
- **CC Switch からの一度きりの移行**：初回起動時、Olenro は既存の `~/.cc-switch` 設定を一度だけ自動インポートするため、既存ユーザーは手動移行なしでプロバイダーと設定を保持できます。旧 `ccswitch://` ディープリンクも後方互換のため引き続き解析されます。
- **中立化されたプロバイダープリセット**：プロバイダープリセット URL からアフィリエイト / リファラルのトラッキングパラメーターをすべて削除しました。機能的なクエリパラメーターは保持しています。
- **独自の自動更新チャネル**：アップデーターと「更新を確認」アクションは Olenro 自身のリリースチャネル（[github.com/lianhr12/olenro](https://github.com/lianhr12/olenro)）を参照するようになりました。
- **CC Switch 3.15.0 の全機能**：一等管理面としての Claude Desktop、強化されたリバースプロキシゲートウェイ、`supports1m` フラグ付きのロールベースモデルマッピング、Codex OAuth のライブモデル探索、フィルター駆動の使用量ダッシュボードがすべて含まれます。上流の機能詳細は [v3.15.0 release notes](v3.15.0-ja.md) を参照してください。

## 変更

### CC Switch fork から Olenro へのリブランド

製品名、ウィンドウタイトル、トレイ、アイコン、アプリ内の参照がすべて Olenro になりました。元の CC Switch プロジェクト（MIT）への帰属表示は README、`LICENSE`、`NOTICE` に保持されています。

### 独立した識別子

- bundle 識別子：`com.olenro.desktop`
- 設定ディレクトリ：`~/.olenro`
- ディープリンクスキーム：`olenro://`（旧 `ccswitch://` スキームも引き続き解析）

### 自動アップデーターのエンドポイント

自動アップデーターのエンドポイントは Olenro 自身の GitHub リリースを参照するようになりました。

## 互換性に関する注意

- **初回起動時のインポート**は `~/.cc-switch` を**一度だけ**読み込み、`~/.olenro` に書き込みます。以降の変更は `~/.olenro` のみに保持されます。元の `~/.cc-switch` ディレクトリはそのまま残されます。
- **旧ディープリンク**：新しい `olenro://` スキームに加え、旧 `ccswitch://` スキームを使うリンクも引き続き解析されます。

## ⚠️ リスク通知

Olenro は上流のリバースプロキシ関連のリスク通知を引き継ぎます。GitHub Copilot や ChatGPT Codex OAuth のリバースプロキシ経路を利用したり、サードパーティプロバイダーを内蔵プロキシゲートウェイ経由でルーティングしたりすると、各プロバイダーの利用規約に違反する可能性があります。これらの機能を有効にすることで、ユーザーは**関連するすべてのリスクを受け入れる**ことになります。Olenro はこれらの機能の利用に起因するアカウント制限・警告・サービス停止について責任を負いません。詳細は [v3.15.0 release notes](v3.15.0-ja.md#️-risk-notice) を参照してください。

## ダウンロードとインストール

[Releases](https://github.com/lianhr12/olenro/releases/latest) にアクセスして適切なバージョンをダウンロードしてください。

### システム要件

| OS      | 最低バージョン               | アーキテクチャ                      |
| ------- | ---------------------------- | ----------------------------------- |
| Windows | Windows 10 以降              | x64                                 |
| macOS   | macOS 12 (Monterey) 以降     | Intel (x64) / Apple Silicon (arm64) |
| Linux   | 下表を参照                   | x64 / ARM64                         |

### Windows

| ファイル                              | 説明                                          |
| ------------------------------------- | --------------------------------------------- |
| `Olenro-v1.0.0-Windows.msi`          | **推奨** - MSI インストーラー、自動更新対応   |
| `Olenro-v1.0.0-Windows-Portable.zip` | ポータブル版、解凍して実行、レジストリ非書込  |

### macOS

| ファイル                      | 説明                                                  |
| ----------------------------- | ----------------------------------------------------- |
| `Olenro-v1.0.0-macOS.dmg`    | **推奨** - DMG インストーラー、Applications にドラッグ |
| `Olenro-v1.0.0-macOS.zip`    | 解凍して Applications にドラッグ、Universal Binary    |
| `Olenro-v1.0.0-macOS.tar.gz` | Homebrew インストールと自動更新用                     |

> macOS ビルドは Apple のコード署名と公証済みです——直接インストールできます。

### Linux

> Linux アーティファクトは **x86_64** と **ARM64**（`aarch64`）の両方で公開されています。アーキテクチャはアセットのファイル名に含まれます——お使いのマシンの `uname -m` の出力に合うものを選んでください：
>
> - `Olenro-v1.0.0-Linux-x86_64.AppImage` / `.deb` / `.rpm`
> - `Olenro-v1.0.0-Linux-arm64.AppImage` / `.deb` / `.rpm`

| ディストリビューション                  | 推奨        | インストール                                                       |
| --------------------------------------- | ----------- | ------------------------------------------------------------------ |
| Ubuntu / Debian / Linux Mint / Pop!\_OS | `.deb`      | `sudo dpkg -i Olenro-*.deb` または `sudo apt install ./Olenro-*.deb` |
| Fedora / RHEL / CentOS / Rocky Linux    | `.rpm`      | `sudo rpm -i Olenro-*.rpm` または `sudo dnf install ./Olenro-*.rpm`  |
| openSUSE                                | `.rpm`      | `sudo zypper install ./Olenro-*.rpm`                               |
| Arch Linux / Manjaro                    | `.AppImage` | 実行権限を付与して実行、または AUR を使用                          |
| その他 / 不明                           | `.AppImage` | `chmod +x Olenro-*.AppImage && ./Olenro-*.AppImage`                |

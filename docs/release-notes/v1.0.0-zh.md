# Olenro v1.0.0

> Olenro 的首个正式发布——基于 CC Switch（MIT）的独立改名 fork，建立自己的应用标识、配置命名空间与更新通道，同时完整继承 CC Switch 3.15.0 的全部能力。

**[English →](v1.0.0-en.md) | [日本語版 →](v1.0.0-ja.md)**

---

## 概览

Olenro v1.0.0 是 Olenro 作为独立项目的**首个正式发布**。Olenro 基于 [CC Switch](https://github.com/farion1231/cc-switch)（MIT，上游 v3.15.0），与原 CC Switch 项目**没有从属关系**。

本版本完整继承 CC Switch 3.15.0 的全部能力——跨 Claude Code、Claude Desktop、Codex、Gemini、OpenCode、OpenClaw、Hermes 的供应商统一管理与切换；内置代理网关 + 按角色的模型映射；用量看板——并将其重建为一个**完全独立的应用**：拥有自己的 bundle 标识、配置目录、deep-link scheme、更新通道，以及中立化后的供应商预设。

如果你正从 CC Switch 迁移，Olenro 会在**首次启动时一次性自动导入**你已有的配置，供应商与设置无需手动操作即可平滑迁移。

**发布日期**：2026-06-01

---

## 重点内容

- **独立应用标识**：全新的 bundle 标识 `com.olenro.desktop`、配置目录 `~/.olenro`、deep-link scheme `olenro://`。Olenro 作为独立应用安装运行，可与原应用并存。
- **从 CC Switch 一次性迁移**：首次启动时，Olenro 会一次性自动导入已有的 `~/.cc-switch` 配置，老用户无需手动迁移即可保留供应商与设置。旧的 `ccswitch://` deep link 仍可解析，保持向后兼容。
- **中立化供应商预设**：已从供应商预设 URL 中移除所有返佣 / 推广追踪参数；功能性查询参数予以保留。
- **自有自动更新通道**：更新器与"检查更新"动作现在指向 Olenro 自己的发布通道（[github.com/horace68/olenro](https://github.com/horace68/olenro)）。
- **完整继承 CC Switch 3.15.0 能力**：Claude Desktop 一等管理面板、强化后的反向代理网关、按角色的模型映射 + `supports1m` 标志、Codex OAuth 实时模型发现、筛选驱动的用量看板等全部包含。上游能力细节见 [v3.15.0 release notes](v3.15.0-zh.md)。

## 变更

### 从 CC Switch fork 改名为 Olenro

产品名、窗口标题、托盘、图标与应用内引用现在均为 Olenro。对原 CC Switch 项目（MIT）的署名保留在 README、`LICENSE` 与 `NOTICE` 中。

### 独立标识符

- bundle 标识：`com.olenro.desktop`
- 配置目录：`~/.olenro`
- deep-link scheme：`olenro://`（旧的 `ccswitch://` scheme 仍可解析）

### 自动更新端点

自动更新端点现在解析到 Olenro 自己的 GitHub releases。

---

## 兼容性说明

- **首启导入**会**一次性**读取 `~/.cc-switch` 并写入 `~/.olenro`；之后的改动只保存在 `~/.olenro`。原 `~/.cc-switch` 目录保持不动。
- **旧 deep link**：除新的 `olenro://` scheme 外，使用旧 `ccswitch://` scheme 的链接仍可继续解析。

## 下载与安装

访问 [Releases](https://github.com/horace68/olenro/releases/latest) 下载对应版本。

### 系统要求

| 系统    | 最低版本                   | 架构                                |
| ------- | -------------------------- | ----------------------------------- |
| Windows | Windows 10 及以上          | x64                                 |
| macOS   | macOS 12 (Monterey) 及以上 | Intel (x64) / Apple Silicon (arm64) |
| Linux   | 见下表                     | x64 / ARM64                         |

### Windows

| 文件                                  | 说明                                |
| ------------------------------------- | ----------------------------------- |
| `Olenro-v1.0.0-Windows.msi`          | **推荐** - MSI 安装包，支持自动更新 |
| `Olenro-v1.0.0-Windows-Portable.zip` | 便携版，解压即用，不写入注册表      |

### macOS

| 文件                          | 说明                                          |
| ----------------------------- | --------------------------------------------- |
| `Olenro-v1.0.0-macOS.dmg`    | **推荐** - DMG 安装包，拖入 Applications 即可 |
| `Olenro-v1.0.0-macOS.zip`    | 解压后拖入 Applications，Universal Binary     |
| `Olenro-v1.0.0-macOS.tar.gz` | 用于 Homebrew 安装和自动更新                  |

> macOS 版本已通过 Apple 代码签名和公证，可直接安装使用。

### Linux

> Linux 资产同时提供 **x86_64** 和 **ARM64**（`aarch64`）两种架构。资产文件名中包含架构标识，请按你机器的 `uname -m` 输出选择对应版本：
>
> - `Olenro-v1.0.0-Linux-x86_64.AppImage` / `.deb` / `.rpm`
> - `Olenro-v1.0.0-Linux-arm64.AppImage` / `.deb` / `.rpm`

| 发行版                                  | 推荐格式    | 安装方式                                                           |
| --------------------------------------- | ----------- | ------------------------------------------------------------------ |
| Ubuntu / Debian / Linux Mint / Pop!\_OS | `.deb`      | `sudo dpkg -i Olenro-*.deb` 或 `sudo apt install ./Olenro-*.deb`   |
| Fedora / RHEL / CentOS / Rocky Linux    | `.rpm`      | `sudo rpm -i Olenro-*.rpm` 或 `sudo dnf install ./Olenro-*.rpm`    |
| openSUSE                                | `.rpm`      | `sudo zypper install ./Olenro-*.rpm`                               |
| Arch Linux / Manjaro                    | `.AppImage` | 添加执行权限后直接运行，或使用 AUR                                 |
| 其他发行版 / 不确定                     | `.AppImage` | `chmod +x Olenro-*.AppImage && ./Olenro-*.AppImage`                |

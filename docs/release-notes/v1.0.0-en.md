# Olenro v1.0.0

> The first official release of Olenro — an independent, rebranded fork of CC Switch (MIT) — establishing its own identity, configuration namespace, and update channel while carrying forward the full CC Switch 3.15.0 feature set.

**[中文版 →](v1.0.0-zh.md) | [日本語版 →](v1.0.0-ja.md)**

---

## Overview

Olenro v1.0.0 is the **first official release** of Olenro as an independent project. Olenro is based on [CC Switch](https://github.com/farion1231/cc-switch) (MIT, upstream v3.15.0) and is **not affiliated with** the original CC Switch project.

This release inherits the complete CC Switch 3.15.0 feature set — unified provider management and switching across Claude Code, Claude Desktop, Codex, Gemini, OpenCode, OpenClaw, and Hermes; the in-app proxy gateway with role-based model mapping; the usage dashboard — and rebuilds it as a **fully independent application** with its own bundle identifier, configuration directory, deep-link scheme, update channel, and neutralized provider presets.

If you are migrating from CC Switch, Olenro performs a **one-time automatic import** of your existing configuration on first launch, so your providers and settings carry over with no manual steps.

**Release date**: 2026-06-01

---

## Highlights

- **Independent Application Identity**: New bundle identifier `com.olenro.desktop`, configuration directory `~/.olenro`, and deep-link scheme `olenro://`. Olenro installs and runs side by side as its own app.
- **One-Time Migration from CC Switch**: On first launch, Olenro automatically imports an existing `~/.cc-switch` configuration once, so existing users keep their providers and settings without manual migration. Legacy `ccswitch://` deep links are still parsed for backward compatibility.
- **Neutralized Provider Presets**: All affiliate/referral tracking parameters have been removed from provider preset URLs; functional query parameters are preserved.
- **Own Auto-Update Channel**: The updater and "Check for updates" action now point at Olenro's own release channel ([github.com/horace68/olenro](https://github.com/horace68/olenro)).
- **Full CC Switch 3.15.0 Feature Set**: Claude Desktop as a first-class managed surface, the hardened reverse-proxy gateway, role-based model mapping with the `supports1m` flag, Codex OAuth live model discovery, and the filter-driven usage dashboard are all included. See the [v3.15.0 release notes](v3.15.0-en.md) for the full upstream feature detail.

## Changed

### Rebranded from CC Switch Fork to Olenro

The product name, window title, tray, icons, and in-app references are now Olenro. Attribution to the original CC Switch project (MIT) is preserved in the README, `LICENSE`, and `NOTICE`.

### Independent Identifiers

- Bundle identifier: `com.olenro.desktop`
- Configuration directory: `~/.olenro`
- Deep-link scheme: `olenro://` (the legacy `ccswitch://` scheme is still parsed)

### Auto-Updater Endpoint

The auto-updater endpoint now resolves against Olenro's own GitHub releases.

---

## Compatibility Notes

- **First-launch import** reads `~/.cc-switch` **once** and writes to `~/.olenro`; subsequent changes are kept in `~/.olenro` only. The original `~/.cc-switch` directory is left untouched.
- **Legacy deep links**: links using the old `ccswitch://` scheme continue to be parsed, in addition to the new `olenro://` scheme.

## ⚠️ Risk Notice

Olenro inherits the reverse-proxy-related risk notices from upstream. Using reverse-proxy paths for GitHub Copilot or ChatGPT Codex OAuth, or routing third-party providers through the in-app proxy gateway, may violate the respective provider's terms of service. By enabling these features, users **accept all associated risks**. Olenro is not responsible for any account restrictions, warnings, or service suspensions that result from using these features. See the [v3.15.0 release notes](v3.15.0-en.md#️-risk-notice) for details.

## Download & Installation

Visit [Releases](https://github.com/horace68/olenro/releases/latest) to download the appropriate version.

### System Requirements

| OS      | Minimum Version              | Architecture                        |
| ------- | ---------------------------- | ----------------------------------- |
| Windows | Windows 10 or later          | x64                                 |
| macOS   | macOS 12 (Monterey) or later | Intel (x64) / Apple Silicon (arm64) |
| Linux   | See table below              | x64 / ARM64                         |

### Windows

| File                                  | Description                                           |
| ------------------------------------- | ----------------------------------------------------- |
| `Olenro-v1.0.0-Windows.msi`          | **Recommended** - MSI installer, supports auto-update |
| `Olenro-v1.0.0-Windows-Portable.zip` | Portable, extract and run, no registry writes         |

### macOS

| File                          | Description                                             |
| ----------------------------- | ------------------------------------------------------- |
| `Olenro-v1.0.0-macOS.dmg`    | **Recommended** - DMG installer, drag into Applications |
| `Olenro-v1.0.0-macOS.zip`    | Extract and drag into Applications, Universal Binary    |
| `Olenro-v1.0.0-macOS.tar.gz` | For Homebrew installation and auto-update               |

> macOS builds are Apple code-signed and notarized — install directly.

### Linux

> Linux artifacts are published for both **x86_64** and **ARM64** (`aarch64`). The architecture is included in the asset filename — pick the one matching your machine's `uname -m` output:
>
> - `Olenro-v1.0.0-Linux-x86_64.AppImage` / `.deb` / `.rpm`
> - `Olenro-v1.0.0-Linux-arm64.AppImage` / `.deb` / `.rpm`

| Distribution                            | Recommended | Installation                                                       |
| --------------------------------------- | ----------- | ------------------------------------------------------------------ |
| Ubuntu / Debian / Linux Mint / Pop!\_OS | `.deb`      | `sudo dpkg -i Olenro-*.deb` or `sudo apt install ./Olenro-*.deb`   |
| Fedora / RHEL / CentOS / Rocky Linux    | `.rpm`      | `sudo rpm -i Olenro-*.rpm` or `sudo dnf install ./Olenro-*.rpm`    |
| openSUSE                                | `.rpm`      | `sudo zypper install ./Olenro-*.rpm`                               |
| Arch Linux / Manjaro                    | `.AppImage` | Add execute permission and run, or use AUR                         |
| Other distros / not sure                | `.AppImage` | `chmod +x Olenro-*.AppImage && ./Olenro-*.AppImage`                |
